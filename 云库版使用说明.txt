============================================================
  生产管理系统 · Turso 云库版 使用说明（小白版）
============================================================

【先说结论，放心看】
  加这个东西，不会把现在的系统搞坏。
  原因很简单：云库版是"另一个程序 + 另一个端口 + 另一份数据"。

     本地版（现在的）：  npm start        端口 5173    数据在 data\pmc.db
     云库版（新加的）：  启动-云库版.bat   端口 5174    数据在 Turso 云端

  两个可以同时开着，互不干扰。
  就算云库版配置写错了，它只会弹一段提示然后关掉，
  绝对不会动你现在电脑上的任何一个文件。


------------------------------------------------------------
【一、什么时候需要云库版】
------------------------------------------------------------
  本地版的数据只存在这一台电脑上。
  如果出现下面这些情况，才需要用云库版：

    · 想在手机上、或家里另一台电脑上看同一份数据
    · 想让车间几台电脑同时录入
    · 怕电脑坏了数据丢了，想存到云端

  如果只是这一台电脑自己用，本地版就够了，不用折腾。


------------------------------------------------------------
【二、开启云库版（3 步）】
------------------------------------------------------------
  第 1 步：注册 Turso 并建一个数据库
      1) 浏览器打开  https://turso.tech
      2) 用 GitHub 账号或邮箱注册、登录
      3) 进入控制台，点 Create Database
         名字随便起，比如 pmc
         地区（Region）选 Singapore 或 Tokyo，离国内近一点更快

  第 2 步：复制两串东西
      进入刚建好的数据库详情页，找到并复制：
        · Database URL   —— 形如  libsql://pmc-xxxxx.turso.io
        · Auth Token     —— 点 Create Token 生成，一长串以 ey 开头的字符
      （Token 只显示一次，先粘到记事本里存好）

  第 3 步：填进配置文件
      1) 在本文件夹里找到  turso.config.json
         如果没看到，先双击一次"启动-云库版.bat"，它会自动生成
      2) 右键 → 打开方式 → 记事本
      3) 把两串东西分别粘到 url 和 authToken 的引号里面，保存

         改成这样（只是举例）：
         {
           "url": "libsql://pmc-abc123.turso.io",
           "authToken": "eyJhbGciOi...很长一串...",
           "port": 5174
         }

        注意：引号、逗号、大括号都要保留，别删。

      4) 双击  启动-云库版.bat
         看到  "✔ 云库连接成功"  就成功了
         再用浏览器打开  http://localhost:5174

------------------------------------------------------------
【三、把本地已有数据搬到云库】
------------------------------------------------------------
  1) 先打开本地版（npm start）→ 左侧"系统配置"→"数据导出与备份"
     → 点【下载完整备份文件（JSON）】，得到 pmc-backup-日期.json
  2) 再打开云库版（端口 5174）→ 同样位置
     → 点【从备份文件还原】→ 选择刚才那个 json 文件
     → 输入二级密码（默认 888888）确认
  3) 刷新页面，数据就搬过去了。

  注意：还原是"覆盖式"的，会把云库里现有的数据清掉再写入。


------------------------------------------------------------
【四、怎么确认我现在用的是哪一个】
------------------------------------------------------------
  看左下角那个小标签：
     · 蓝色  "libSQL · 本地"   → 本地版，数据在本机
     · 绿色  "libSQL · 云库"   → 云库版，数据在 Turso

  系统配置 →"数据导出与备份"里也有"数据引擎信息"，会写明
  当前数据目标和文件位置。


------------------------------------------------------------
【五、出问题了怎么办 / 怎么撤销】
------------------------------------------------------------
  Q: 双击 bat 之后提示"云库连接失败"？
  A: 按顺序检查：地址是不是 libsql:// 开头、Token 有没有复制完整、
     电脑能不能上网。改好 turso.config.json 再双击一次即可。
     这个错误不影响本地版。

  Q: 我不想用云库了，怎么彻底恢复原样？
  A: 把 turso.config.json 删掉就行。
     本地版从头到尾一个字都没改过，npm start 照常用。

  Q: 云库版会占用我电脑的硬盘吗？
  A: 不会。云库版不写本地数据库文件，只有你的账号和登录状态
     存在浏览器里。


------------------------------------------------------------
【六、相关文件一览】
------------------------------------------------------------
  turso.config.json         ← 你填的云库配置（删掉它 = 撤销云库版）
  turso.config.example.json ← 配置模板，别改，删了会自动重新生成
  start-turso.js            ← 云库版启动器（只在连接云端时用）
  启动-云库版.bat            ← 双击这个就能开云库版
  云库版使用说明.txt         ← 就是本文

  云端和本地用的是同一套网页代码，所以界面、功能完全一样。
