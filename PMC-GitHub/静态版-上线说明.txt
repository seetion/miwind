============================================================
   生产管理系统 · 静态版   上线说明（小白版）
------------------------------------------------------------
   一句话原理：
   网页文件放在 GitHub 上（免费、永久），
   数据放在 Turso 云库里（免费额度足够 2~3 人用），
   浏览器直接连云库，所以不需要任何服务器。
   把网址发给同事，谁打开都看到同一份数据。
============================================================


【第一步】注册 Turso，拿到两串东西
------------------------------------------------------------
 1. 浏览器打开 https://turso.tech ，用 GitHub 或邮箱注册登录
 2. 进入控制台 → Create Database → 名字填 pmc → 地区选 Singapore 或 Tokyo
 3. 进入这个数据库的详情页，复制两串东西：
      · Database URL  → 形如  libsql://pmc-xxxxx.turso.io
      · Auth Token    → 点 Create Token 生成，一长串以 ey 开头的字符
        （Token 只显示一次，先粘到记事本存好）

 免费额度：2~3 个人日常录入完全用不完。


【第二步】把这个文件夹上传到 GitHub
------------------------------------------------------------
 你这台电脑还没装 git，所以用最简单的图形工具：

 1. 打开 https://desktop.github.com 下载 GitHub Desktop，安装
 2. 打开后登录你的 GitHub 账号（没有就去 github.com 注册一个，免费）
 3. 菜单 File → Add local repository → 选择这个文件夹：
        c:\Users\Dell\Desktop\PMC
    如果提示"不是 Git 仓库"，点它给的 "create a repository" 即可
 4. 左下角填一句说明（例如 第一次上传），点 Commit
 5. 点右上角 Publish repository
    ⚠ 把 "Keep this code private" 的勾去掉（Pages 免费版需要公开仓库）

 项目里的 .gitignore 已经配好了，会自动跳过：
    node_modules（461MB）、安装包与 dist（各 200 多 MB）、data（你的真实数据）、
    turso.config.json（密钥）。所以实际上传只有几百 KB，很快。

 ⚠ 千万别手动把 node_modules、安装包、data 文件夹拖进去，会传不上去或泄露数据。


【第三步】开启 GitHub Pages（让网页能打开）
------------------------------------------------------------
 1. 在浏览器打开你的仓库页面：https://github.com/你的用户名/PMC
 2. 点上方 Settings（设置）→ 左侧找到 Pages
 3. Source 选 "Deploy from a branch"
 4. Branch 选 main，右边的文件夹选 "/docs"，点 Save
 5. 等 1~2 分钟，刷新页面，顶部会出现你的网址：

        https://你的用户名.github.io/PMC/

   点开它，就是你的生产管理系统了。


【第四步】第一次打开：配置云库
------------------------------------------------------------
 1. 打开上面的网址，会自动弹出"首次使用 · 配置数据库连接"
 2. 把第一步复制的 Database URL 和 Auth Token 粘进去
 3. 点【测试连接】→ 出现绿色"连接成功"就对了
 4. 点【保存并进入】→ 系统会自动建表，并创建默认账号：

        账号 admin    密码 admin123

 5. 立刻去 系统配置 → 账号与安全 把登录密码和二级密码改掉


【分享给同事】
------------------------------------------------------------
 方式一（推荐，同事不用配置）：
   点右上角【云库连接】→ 里面会显示一条"分享链接"，点【复制链接】，
   发给同事，他们打开就能直接用同一份数据。

 方式二：
   直接发主网址，然后各自粘贴一次 URL 和 Token。


【把老数据搬过来】
------------------------------------------------------------
 在桌面版/网页版里：系统配置 → 数据导出与备份 →【下载完整备份文件（JSON）】
 回到静态版：     系统配置 → 数据导出与备份 →【从备份文件还原】→ 选这个 json
                  （需要输入二级密码，默认 888888）


【注意事项（认真看）】
------------------------------------------------------------
 1) 这个方案的连接密钥是写在浏览器里的，拿到链接的人理论上能直接操作数据库。
    你们是 2~3 个人内部用，问题不大；但不要把链接发到公开的地方。
 2) 免费额度用超了 Turso 会限流。日常录报表的量远远用不到，放心。
 3) 数据在云端，但备份习惯还是要养成：系统配置 → 下载完整备份文件。
 4) 游客模式依然有效：不登录只能看，不能录。但请记住这只是"防手滑"，
    不是真正的安全防护。
 5) 手机浏览器也能打开用，界面会自动适应。


【改了代码怎么更新线上】
------------------------------------------------------------
 1. 用 GitHub Desktop 打开仓库 → 它会自动显示哪些文件改了
 2. 填一句说明 → Commit → 右上角 Push origin
 3. 等 1 分钟，刷新网址就是新版了


【出问题怎么办】
------------------------------------------------------------
 Q: 打开网址是 404？
 A: Pages 还在部署，等 2 分钟再看；或者检查第三步的文件夹有没有选对 "/docs"。

 Q: 一直弹"连接失败"？
 A: 点右上角【云库连接】→ 重新粘贴 URL 和 Token → 测试连接。
    把红字报错内容发我，我帮你看。

 Q: 想换一个数据库？
 A: 右上角【云库连接】→【清空】→ 填入新的 URL 和 Token。

 Q: 同事打开后数据是空的？
 A: 说明他连的不是同一个库。用"分享链接"发给他最稳妥。

 Q: 不想用了？
 A: 仓库 Settings → 最下面 Delete this repository，然后把 Turso 上的库删掉即可。
